# Build an LLM from Scratch — Learning Journey

This repository documents my learning journey while studying how Large Language Models are built from scratch.

The goal of this repository is not just to copy course code.

For every section, I follow a practical learning workflow:

1. Watch and understand the course session.
2. Rewrite the concepts in my own words.
3. Create structured Markdown notes.
4. Implement the concepts myself in notebooks.
5. Experiment with the code and understand the results.
6. Commit and push each completed learning stage to GitHub.

This repository will therefore grow step by step as I progress through the course.
